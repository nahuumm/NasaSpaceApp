# NasaSpaceApp
Plataforma de apoyo a la toma de decisiones agrícolas para el desafío Cambio de campo (backend)

## Cómo desarrollar localmente
1. Clona el repositorio: `git clone https://github.com/nahuumm/NasaSpaceApp.git`
2. Levanta los contenedores: `docker-compose up --build`
3. Frontend en: http://localhost:3000
4. Backend en: http://localhost:8000/docs
